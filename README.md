# LVGL ported to the GD32F5HC EVAL.

The [GD32F5HC Development Kit] is an affordable development board with:
- GD32F5HCVKT6 microcontroller (ARM Cortex-M33 core, FPU, DSP instructions, TrustZone security)
- 2048 KB on-chip Flash memory and 320 KB on-chip SRAM
- High-speed peripheral interfaces including  USB OTG and CAN FD
- On-board GD-LINK debugger/programmer for one-click download and debugging
- On-board high-precision RTC clock and temperature sensor
- Multiple user LEDs, function keys and universal expansion pin headers
- Support for low-power mode development and industrial-grade wide temperature operation
- 240x320 (QVGA) TFT
